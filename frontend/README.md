# 🎛️ Interface

This folder contains the React/TypeScript interface and Vite configuration.

- 🧭 `src/main.tsx` wires workspace tabs and app state.
- 🧩 `src/widgets.tsx` contains shared artwork and playlist-list components.
- 🎨 `src/style.css` contains themes and responsive layout.
- 🖼️ `public/resources/` contains UI artwork and icons.
- 📦 `dist/` is generated by the production build; edit `src/`, not the generated bundle.

See [Current Library](../docs/CURRENT_LIBRARY.md) for its table and selection actions.
