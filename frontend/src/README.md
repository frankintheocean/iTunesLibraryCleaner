# 🧩 Interface source

- 🎛️ `main.tsx` contains workspace navigation, overview, Current Library, playlist controls, and Settings.
- 🎨 `style.css` contains the app theme, responsive layout, and component styles.
- 🎧 `LastFM.tsx` displays Last.fm profiles and listening charts.
- 🖼️ `widgets.tsx` shares album-art loading and playlist track controls.
- 🔗 `api.ts` calls the approved local backend bridge.
- 🧠 `state.ts` keeps workspace navigation state.

Build with `npm run build`; do not edit compiled files under `frontend/dist/` by hand.
